# Literature surveys (July 25, 2026)

Three agent-produced surveys commissioned to pick the program's next steps.
Each was given the program's exact setting (expanding return maps, sparse
halting sets, no-congruence theorems, LTE/Baker run bounds) and asked for
honest transferability assessments, not just summaries.

- `bbchallenge-ecosystem.md` — cryptid census 2025–26 (Fenrir, new Space-Needle-like
  machine), BB(5)/BB(6) status, decider technology (CTL/FAR/WFAR/RepWL/CPS) in
  mathematical detail, certification practice (Rocq/Lean), FRACTRAN + register-machine
  busy beaver censuses. Headline: the base-q regular-invariant search on an arithmetic
  cryptid map is untried by anyone; no census of guarded-affine counter machines exists.
- `collatz-techniques.md` — Tao 2019 (and why expansion blocks it), Krasikov–Lagarias
  difference inequalities (and why the sign flips in our favor), transfer operators +
  certified spectral gaps, 2-adic/automata formulations, Baker/S-unit/m-cycle
  architecture, orbit-avoids-sparse-set literature (affine sieve inapplicable, FLP
  window rigidity). Headline: halting-basin density theorem is provable now; Baker
  escalation is the only single-orbit technology.
- `decidability-termination.md` — Kurtz–Simon/Conway/Ben-Amram exact statements,
  the interval-vs-valuation (MSB/LSB) branching fault line for 1D piecewise-affine
  reachability, Skolem landscape, non-termination provers' certificate classes
  (provably inexpressive for us), Büchi arithmetic + Dhiman–Pandey non-definability,
  Carelli ICALP 2026 bridge. Headline: automatic-set invariants are the one
  certificate class not excluded by our theorems.

The synthesis and ranked plan derived from these: `../NEXT_STEPS.md`.
